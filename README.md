# 田畑式タイマー (Tabata Timer)

ブラウザで動く田畑式(タバタ式)インターバルタイマーです。
インストール不要で、スマホのホーム画面に追加すればアプリのように使えます。

**https://ydaigo.github.io/tabata-timer/**

## 概要

準備 → 運動 → 休憩 を設定したラウンド数だけ繰り返します。
画面の色(準備=オレンジ / 運動=赤 / 休憩=青 / 完了=緑)と残り秒数の大画面表示で、
運動中にちらっと見るだけで今どのフェーズかが分かります。

初期設定は **準備5秒 + 運動50秒 / 休憩10秒 × 5ラウンド**。

## 機能

- 準備・運動・休憩の秒数とラウンド数を自由に設定
- 設定はクッキーに1年間保存され、次に開いたときに復元される
- フェーズ切り替え時のビープ音と、残り3秒からのカウントダウン音
- 音と同時にバイブレーション(対応端末のみ)
- 一時停止・再開・リセット
- 計測中は画面が消灯しない(Screen Wake Lock)
- PWA対応。ホーム画面に追加でき、オフラインでも動作する
- ダークモード対応

## 使い方

1. 上記URLを開く
2. 必要なら準備・運動・休憩・ラウンド数を変更する(変更すると自動で保存されます)
3. 「スタート」を押す

スマホのホーム画面に追加する場合:

- **iPhone (Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**: メニュー → 「アプリをインストール」

## 音が鳴らないときは

- 音は最初の「スタート」のタップで有効になります。必ずボタンから開始してください
- iPhone のマナーモード対策として無音の音声をループ再生しています。
  それでも鳴らない場合は、本体の音量と消音スイッチを確認してください
- タイマー計測中にブラウザをバックグラウンドにすると、OSの制限で音が止まることがあります

## 構成

静的ファイルのみで、ビルド作業は不要です。

| ファイル | 内容 |
| --- | --- |
| `index.html` | HTML・CSS・JavaScript をすべて含む本体 |
| `sw.js` | オフライン動作用の Service Worker |
| `manifest.webmanifest` | PWA のマニフェスト |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アイコン |

ローカルで確認する場合は、クッキーと Service Worker を有効にするため
`file://` ではなく HTTP サーバー経由で開いてください。

```sh
python -m http.server 8000
# http://localhost:8000 を開く
```

`index.html` を更新したときは、キャッシュを更新するため `sw.js` の `CACHE` の
バージョン名(`tabata-vN`)も上げてください。
